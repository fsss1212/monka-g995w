# MONKA G995W для Linux

Нативный конфигуратор для двух USB-интерфейсов, снятых с одного комплекта MONKA G995W. Поддерживает редактирование DPI, частоты, подсветки, кнопок, макросов и локальных профилей. Степень проверки каждой функции указана в таблице ниже.

| Подключение | VID:PID | bcdDevice | Строка USB | Настройка |
| --- | --- | --- | --- | --- |
| Приёмник 2,4 ГГц | `1d57:fa60` | `0105` | Beken / G995W MOUSE | Интерфейс 02 |
| Кабель USB-C | `1d57:fa61` | `0104` | Beken / USB Gaming Mouse | Интерфейс 02 |

Linux выделил `/dev/hidraw2` клавиатуре, `hidraw3` указателю, `hidraw4` управляющему интерфейсу и `hidraw5` NKRO-клавиатуре. Имена узлов могут измениться. Программа проверяет VID, PID, bcdDevice, строки, номер интерфейса и SHA-256 HID-дескриптора при каждом новом открытии. Подключайте для настройки один транспорт.

## Сборка и установка на EndeavourOS / Arch

```bash
sudo pacman -S --needed make python python-pyqt6 hidapi
git clone https://github.com/fsss1212/monka-g995w.git
cd monka-g995w
make
make test
make install
sudo make install-udev
```

Установщик создаёт `~/.local/bin/monka-g995w` и пункт меню **MONKA G995W**. Для применения udev-правила к уже подключённому устройству переподключите кабель или приёмник. Доступ пользователя к обоим вариантам проверен на EndeavourOS. Программа запускается от пользователя активного локального сеанса.

```bash
~/.local/bin/monka-g995w
~/.local/bin/monka-g995w --probe
```

Запуск без установки — `./build/monka-g995w`. `--probe` открывает правильный HID-интерфейс и выводит полученные входные отчёты в течение нескольких секунд. Команды записи в этом режиме отсутствуют.

## Заряд в системном трее

Значок показывает приблизительный процент из последнего отчёта мыши. Наведите курсор, чтобы увидеть время отчёта. Закрытие окна оставляет мониторинг в трее. Щелчок по значку или повторный запуск из меню приложений открывает настройки. Действие **Выйти** в меню значка завершает мониторинг.

Для фонового запуска используйте `~/.local/bin/monka-g995w --tray`. Эту команду также можно добавить в автозапуск рабочего стола. До первого отчёта и при отключении USB-интерфейса значок показывает прочерк.

Удаление приложения и правила:

```bash
cd monka-g995w
make uninstall
sudo make uninstall-udev
```

После удаления правила переподключите устройство, чтобы отозвать ACL. Профили и история отправки находятся в `${XDG_CONFIG_HOME:-~/.config}/monka-g995w/profiles.json`. Экспорт создаёт переносимый JSON. Сброс профиля загружает значения Marvo в редактор, после чего их можно отправить мыши.

## Официальная утилита и выбор базы

Версия конфигуратора Marvo — **V1.0.0.0** по ресурсам About из [страницы продукта Marvo](https://www.marvo-tech.com/products/monka-guru-g995w-wireless-gaming-mouse). SHA-256 [официального установщика](https://cdn.shopify.com/s/files/1/0521/6075/7938/files/MONKA_G995W_mouse.exe?v=1733995153) — `863901f6b58679524fde3561d6dc2da8ebf5c43c9226b087efaf09e7014d3d04`. SHA-256 извлечённого `Mouse.exe` — `e27dc0ca1ad748b24a695956ebf2aa78cc5b91dd8bfd22a72292652e24f142d6`. [Руководство Marvo](https://www.marvogaming.eu/manualy/G995W.pdf) описывает шесть ступеней DPI, сочетание кнопок для RGB и различия между USB, 2,4 ГГц и BT. [Архив MONKA от 15.02.2025](https://monka.gg/wpfd_file/software_monka-guru-g995w-mouse-updated-app/) содержит инструменты обновления мыши и приёмника. Их не запускали.

- [HIDAPI](https://github.com/libusb/hidapi) используется как транспорт. Системная `libhidapi-hidraw.so.0` работает с интерфейсом 02 через стандартный драйвер `usbhid`. Графический интерфейс написан на PyQt6.
- В [libratbag](https://github.com/libratbag/libratbag) на `8235b5bb` совпадений по модели и VID нет. [Piper](https://github.com/libratbag/piper) использует ratbagd и унаследовал бы отсутствие драйвера.
- [OpenMouse](https://github.com/OpenMouse-Project/mouse-protocol) на `93c4cc60` описывает несколько несовместимых мышей с общими `1d57:fa60/fa61`, включая Attack Shark и Delux. Протокол этой MONKA подтверждён непосредственно по пакету Marvo.
- [Pressplay ATLAS](https://github.com/erlanggardr/pressplay-atlas-driver) на `a733ce17` подсказал структуру семейства команд и способ воспроизвести пакетные функции в Unicorn. У G995W отличаются шкала DPI, служебные поля подсветки и входные события. В репозиторий вошла самостоятельная реализация по данным G995W. Код стороннего приложения, установщик, DLL, графика и прошивки не входят в сборку.

Код приложения предоставлен по GPL-3.0. Тексты лицензий системных библиотек устанавливаются пакетами дистрибутива.

| Обновление прошивки | Отдельные пакеты Marvo для приёмника и мыши. | Отсутствует. | Прошивки не запускались. |

Редактор показывает локальный профиль. В разделе **Кнопки** точки на схеме мыши и строки назначений открывают редактор выбранной кнопки. Раздел **Подсветка** показывает анимированный предпросмотр выбранного эффекта. Основная кнопка внизу отправляет настройки открытого раздела. Меню рядом позволяет выбрать отдельную группу или отправить все настройки. Действие **Последние отправленные значения** в меню профиля показывает последний набор по каждой группе, транспорт и наличие подтверждения. Телеметрия с устройства выводится в боковой панели. Стандартные GET Feature для отчётов 04/05/06/08/09 завершились по тайм-ауту по кабелю и через приёмник. Поэтому начальные значения, которые могли быть изменены владельцем, автоматически не заменялись.

В [описании протокола](PROTOCOL.md) приведены размеры, поля, дескрипторы и проверки. Для оставшихся аппаратных проверок полезен экспорт текущего профиля Windows или короткая USBPcap-трасса запуска и одного изменения за раз. Для LOD, сна и Bluetooth нужна трасса в соответствующем режиме, если Windows действительно показывает эти элементы на данном экземпляре.
